Core competitiveness

The causal graph behind every prediction

We don't prompt an agent to "act like a 27-year-old in NYC." We model the population's decision structure as a graph of weighted causal relationships — then personalize it to each user. Explore it live below.

Interactive · drag nodes, hover edges. Master graph → individual graph → simulation → flywheel. Open full screen ↗
🌐

Master graph

A population-level causal model — traits, context, and behaviors with weighted edges (β) — synthesized from large-scale data and the literature.

👤

Individual graph

Each user's measured traits are "clamped" in; the rest is inferred from the master graph. The more we measure, the higher the fidelity.

✦

In-graph vs. generative

Known outcomes resolve through the causal graph with high confidence. Novel "what-ifs" are estimated generatively and added back to the model.
